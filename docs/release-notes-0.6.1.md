# VoicePrompt 0.6.1

- Check for app updates in Settings. New stable releases appear automatically,
  with an Update now action in the main window.
- Download and verify an update, then choose Restart to update or keep working.
- Update preparation protects active dictation, recoverable recordings, and
  unsaved settings. Application updates preserve your saved data and model cache.
- Release downloads use free GitHub hosting and cryptographic update signatures.
  Windows publisher signing is separate; Windows may still show trust warnings.

This is the first version containing the in-app updater. Users of older versions
must install this version manually once. Subsequent stable releases can use the
in-app update flow.
